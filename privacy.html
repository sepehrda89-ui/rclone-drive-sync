Privacy Policy

App: rclone My Documents sync

Who uses this app

Only its owner. It is a personal backup tool and is not offered to anyone else.

What data it accesses

With the owner's permission, the app accesses the owner's Google Drive to upload files from the owner's own computer and to check which files have changed.

How data is used and stored

  • Files move only between the owner's computer and the owner's Google Drive.
  • The Google sign-in token is stored only on the owner's computer.
  • No data is collected, sold, shared with third parties, or used for advertising.
  • No analytics or tracking are used.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
